# SASE SJSU Website

The website for the Society of Asian Scientists and Engineers (SASE) at San José State University, built with [Next.js](https://nextjs.org) and [Tailwind CSS](https://tailwindcss.com).

## Prerequisites

- [Node.js](https://nodejs.org) 20 or later (developed on Node 22)
- npm (bundled with Node.js)

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3200](http://localhost:3200) in your browser to see the result. The dev server is configured to run on port **3200**. The page auto-updates as you edit files.

You can start editing the site by modifying the files under `src/app` — for example, `src/app/page.tsx`.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server (with Turbopack) at `http://localhost:3200`. |
| `npm run build` | Create an optimized production build. |
| `npm run start` | Serve the production build at `http://localhost:3200` (run `npm run build` first). |
| `npm run lint` | Run ESLint to check for code issues. |
